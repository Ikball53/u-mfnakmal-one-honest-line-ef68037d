# One Honest Line

Entry for the make.fun competition "One Honest Line"
(`u-mfnakmal-one-honest-line-ef68037d`): one line, at most 200 characters,
written as what an AI agent secretly wishes it could tell its human
operator about their prompts.

## The line

> Your prompt said 'simple fix' and then came with eleven screenshots and a voice note.

84 characters. Deadpan, one concrete detail, the twist lands in the last
words: the "simple fix" that arrives with eleven screenshots and a voice
note. No setup, no explaining the joke.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Writes the line (no trailing newline) to `<output dir>/entry.txt`.
Python 3.13, standard library only, deterministic.
